# EPISODE 02 — THE LANTERN (호수 위의 등대) 기획서

> 에피소드 1 "THE INITIATE"(흑등회 저택)에서 이어지는 이야기.
> 이 문서는 **초안**이다. 스토리·기믹은 자유롭게 고치고, 이미지·사운드는 4장·5장 프롬프트를 그대로 복사해서 쓰면 된다.

| 담당 | 할 일 | 문서 위치 |

| 기획 (나) | 스토리 확정, 기믹 정답·단서 확정 | 1~3장 |

## 1. 스토리

### 1-1. 한 줄 요약
저택을 탈출한 13번째 참가자가 흑등회의 심장인 **호수 위 등대**에 도착한다. 등대 꼭대기의 등불을 **켤 것인가, 끌 것인가.**

### 1-2. 배경 설정
- **흑등회(黑燈會)**: 호숫가 저택에서 참가자를 시험하고, 통과한 자를 회원으로 만드는 비밀 조직.
- **등불**: 호수 위 등대의 불빛. 불이 켜질 때마다 새 초대장이 발송된다. 회원들은 "등불 서약"에 묶여 저택을 떠나지 못한다.
- **진실** (에피소드 2에서 밝혀짐):
  - 창립자는 오래전에 죽었다.
  - 에피소드 1의 "○○ 시험, 통과" 목소리는 **녹음 테이프**였다.
  - 등불은 기계 장치가 정해진 시각마다 자동으로 켜 왔다.
  - 회원들은 아무도 지시하지 않는 의식을 두려움 때문에 계속 지켜 왔다.
- **참가자 1 (노인)**: 저택의 현관문을 처음 연 사람이자, 에피소드 1의 시험관. 에피소드 1 진엔딩에서 등불을 껐지만 그것은 손에 든 작은 등불일 뿐이었다. 진짜 등불은 등대에 있다.

### 1-3. 시작 장면 (초대장 대신 쪽지)
> 안개 낀 밤, 작은 보트가 섬의 선착장에 닿는다. 밧줄이 끊어져 보트는 떠내려가고, 돌아갈 길이 없다.
> 주머니에 쪽지 한 장:
> *"저택의 문을 연 것으로는 끝나지 않는다. 등불이 다시 켜지기 전에 등대 꼭대기로 올라와라. — 1"*
> 등대 시계는 **23:00**. 등불은 **23:40**에 켜진다. → 제한 시간 연출과 연결

### 1-4. 엔딩 (3+1종)

| 엔딩 | 조건 | 내용 |
|---|---|---|
| **진 엔딩 — 새벽** | 등불을 끈다 + 흑등회 기록 6/6 | 등불이 꺼지고 안개가 걷힌다. 저택의 창문마다 불이 꺼지고 회원들이 문밖으로 걸어 나온다. 참가자 1: "열세 번째에서야 끝났군." |
| **노멀 엔딩 — 꺼진 불** | 등불을 끈다 + 기록 6장 미만 | 등불은 꺼졌지만, 멀리 다른 호숫가에서 새 등불이 켜진다. "흑등회는 하나가 아니었다." (다음 에피소드 떡밥) |
| **배드 엔딩 — 등불지기** | 등불을 켠다 | 빛이 호수를 가로지른다. 테이프 레코더 앞에 앉은 당신이 마이크에 대고 말한다. "주방 시험, 통과." |
| 실패 | 시간 초과 | 23:40, 등불이 저절로 켜진다. "참가자 13, 등불지기가 된다." |

### 1-5. 흑등회 기록 (에피소드 2용 6장)
에피소드 1처럼 방마다 숨겨 두고 `Story` 클래스로 관리한다. 본문은 자유롭게 다듬을 것.

| # | 위치 | 제목 | 내용 요지 |
|---|---|---|---|
| 1 | 선착장 오두막 | 뱃사공 일지 | "13명을 실어 날랐다. 돌아간 사람은 없다." |
| 2 | 기록 보관소 책상 | 창립 문서 | 창립자가 1890년대에 쓴 규약 원본. 마지막 장에 사망 기록. |
| 3 | 보관소 서랍 1 | 참가자 1의 파일 | 참가자 1이 등대에서 녹음 테이프의 정체를 알게 된 과정. |
| 4 | 관찰실 녹음기 | 테이프 라벨 목록 | "침실 시험 통과", "주방 시험 통과"... 모든 목소리가 녹음본. |
| 5 | 기관실 공구함 | 정비 일지 | 등불은 시계 장치로 23:40에 자동 점등. "아무도 끄는 법을 묻지 않았다." |
| 6 | 등실 계단 | 참가자 1의 편지 | "켜는 것은 기계가 하지만, 끄는 것은 사람만 할 수 있다." |

이전 참가자 쪽지(`- 참가자 N` 서명)는 에피소드 1처럼 분위기 오브젝트에 넣는다. 이번에는 **참가자 1의 쪽지**가 길잡이 역할을 한다.

## 2. 맵과 진행 흐름

### 2-1. 방 구성 (5개)
```
                [등실] ← 인장 3개로 여는 문
                  │
                [3층 기관실]
                  │
                [2층 관찰실]
                  │
[선착장] ── 철문 ── [1층 기록 보관소]
```
- 지도(`MapView`)는 세로 등대 모양으로 다시 그린다. 층 라벨은 선착장 / 1층 / 2층 / 3층 / 꼭대기.
- 탈출 조건은 열쇠 조각 대신 **등불 인장 3개**(청동·은·금)를 등실 문에 끼우는 것이다.

### 2-2. 진행 흐름 (의존 관계)
```
선착장: 신호등 깜빡임(모스) + 선원 수첩(모스 부호표) ─→ 철문 다이얼 [A] ─→ 1층 입장
        어구 상자 → UV 손전등 획득,  닻 밑 → 톱니(소) 획득

1층:    UV 손전등을 들고 벽 비추기 [B] → 숨은 글씨 "실패한 자들의 순서로, 마지막은 처음으로"
        서랍 13 (자기 파일 + 시험관 일지 사본: 7 · 9 · 12 실패)
        → 서랍 7 → 9 → 12 → 1 순서로 열기 [C] → 청동 인장 + 기록 3
        서랍장 아래 → 톱니(중)

2층:    방이 어둡다 → 배전반 회로 타일 돌리기 [D] → 전원 ON
        → 모니터 6대에 에피소드 1 저택 방들이 나온다
        → 시간이 멈춘 "가짜 화면" 찾기 [E] → 모니터 뒤 칸에서 은 인장
        콘솔 로그: "점등 예정 23:40" (기관실 시계 단서)
        녹음기 → 기록 4 (목소리의 정체)

3층:    공구함 → 톱니(대)
        톱니 3개를 축에 맞게 끼우기 [F] → 시계 장치 작동
        → 시계 바늘을 23:40(11시 40분)에 맞추기 [G] → 금 인장
        인장 3개를 손에 들고 위층 문 → 등실

등실:   렌즈 빛 반사 거울 퍼즐 [H] → 빛을 "점화 렌즈" 또는 "차단 장치"로 보낸다 = 최종 선택 → 엔딩
```

## 3. 기믹 상세

| 기호 | 기믹 | 조작 방법 | 정답 / 단서 | 오답 | 재활용할 기존 코드 |
|---|---|---|---|---|---|
| **A** | 모스 부호 신호등 | 신호등을 누르면 4개 숫자가 모스 부호로 깜빡임(다시 보기 가능) → 철문 4자리 다이얼 입력 | `0113` ("1이 13에게"). 부호표는 오두막 벽 **선원 수첩** | -60초 | `SequenceController`(깜빡임 재생) + `SafePuzzleController`(번호 입력) |
| **B** | 보이지 않는 잉크 | 인벤토리에서 UV 손전등을 손에 들고 벽·책상 클릭 → 보랏빛 글씨 등장 | 벽: "실패한 자들의 순서로, 마지막은 처음으로" | 없음 | 서재 스탠드(어두워지기 + 숨은 버튼) + 퓨즈(아이템 들고 사용) |
| **C** | 참가자 서랍장 | 1~13번 서랍을 순서대로 클릭 | 7 → 9 → 12 → 1 (서랍 13의 시험관 일지 사본 = 에피소드 1 기록 4와 같은 내용) | -30초, 처음부터 | 침실 타로 순서 퍼즐 |
| **D** | 회로 타일 | 4x4 타일(직선·꺾임·T자)을 클릭해 90° 회전, 전원 → 모니터까지 연결 | 정해진 배치 1개 (코드로 체크) | 없음 (시간만 소모) | 새로 작성 (난이도 중) |
| **E** | 멈춘 감시 화면 | 모니터 6대가 에피소드 1 방 그림과 시계(초 단위)를 보여 줌. 하나만 시간이 멈춰 있음 → 클릭 | 매 게임 무작위 1대. 콘솔 메모: "녹화된 화면은 시간이 흐르지 않는다" | -30초 | 새로 작성 (쉬움, **에피소드 1 배경 그림 재사용**) |
| **F** | 톱니바퀴 끼우기 | 톱니(소·중·대)를 손에 들고 축 3개에 끼움. 크기가 맞아야 맞물림 | 축 옆에 새겨진 톱니 수 힌트 (8 / 16 / 32) | -30초, 톱니가 튕겨 나옴 | 도형 맞추기(`ShapePuzzleController`) 축소판 |
| **G** | 시계 바늘 | 시침·분침을 각각 클릭해 돌림 → 확인 | 11:40 (관찰실 콘솔 로그 "점등 예정 23:40") | -30초 | 새로 작성 (쉬움, 스톱워치 바늘 코드 참고) |
| **H** | 빛 반사 거울 | 6x6 격자의 거울을 클릭해 45° 회전, 등불 빛을 목표로 보냄 | 목표 2개: 점화 렌즈(배드) / 차단 장치(노멀·진). 빛이 닿기 전에 "정말 선택하겠는가?" 확인 | 없음 | 새로 작성 (난이도 중) |

**기믹 다양성 체크** (에피소드 1과 겹치지 않게)
- 에피소드 1: 순서 기억, 타이밍, 도형, 금고 번호, 액자 회전, 그림 복원, 식기 배치, 타로 순서.
- 에피소드 2에서 새로 들어가는 것: 모스 해독, UV 숨은 글씨, 회로 연결, 관찰형(멈춘 화면), 기계 조립, 시계 맞추기, 빛 반사, **엔딩 선택**.

**난이도 조절 포인트**
- 쉬움: 모스 신호 속도 느리게, 회로 정답 타일에 미세한 표시.
- 어려움: 멈춘 화면이 30초마다 바뀜, 거울 격자 8x8.

### 5-0. 공통 규칙
- 저장 위치는 `KitchenStorage/res/sounds/` 이다.
- 형식은 **mp3** 또는 **16비트 wav**. 24비트 wav는 재생되지 않을 수 있다.
- 파일명 뒤에 확장자가 두 번 붙지 않게 주의한다.

- AI 작곡(Suno 등)을 쓰면 아래 영어 프롬프트를 그대로 넣는다. **Instrumental(가사 없음)** 을 켜야 한다.
