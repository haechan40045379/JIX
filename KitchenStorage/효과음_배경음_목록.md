# 효과음 / 배경음 목록

찾은 파일은 `res/sounds/` 폴더에 아래 **파일명 그대로** 넣으면 됩니다.
형식은 **.wav** (효과음) / **.mp3** (배경음) 권장. 효과음은 1~2초, 배경음은 1~3분짜리 루프(반복 재생되는 곡).

## 배경음 (BGM)

| 파일명 | 쓰이는 곳 | 분위기 / 검색어 |
|---|---|---|
| `bgm_menu.mp3` | 메인 메뉴, 에피소드 선택 | 조용하고 음산한 피아노·오르골 (mystery piano, music box horror) |
| `bgm_manor.mp3` | 침실·서재·현관·식당 | 낮게 깔리는 앰비언트, 긴장감 (dark ambient, suspense loop) |
| `bgm_basement.mp3` | 주방·지하 저장고 | 더 어둡고 축축한 느낌, 물방울·웅웅거림 (basement ambience, horror drone) |
| `bgm_hurry.mp3` | 남은 시간 5분 이하 | 빨라지는 현악·심장 박동 (tension rising, heartbeat) |
| `bgm_clear.mp3` | 탈출 성공 화면 | 해방감, 잔잔한 엔딩 (calm ending, relief) |
| `bgm_gameover.mp3` | 게임 오버 화면 | 낮은 음의 불길한 마무리 (sad horror ending) |

## 무료로 받을 수 있는 곳 (저작권 확인 필수)

- **Pixabay** (pixabay.com/sound-effects, /music): 출처 표기 없이 사용 가능
- **Freesound** (freesound.org): 무료 회원가입. 파일마다 라이선스(CC0 / CC-BY)가 다르니 CC0 권장
- **Mixkit** (mixkit.co/free-sound-effects): 무료, 회원가입 없음
- **유튜브 오디오 보관함**: 배경음 위주

발표 자료에는 사용한 음원 출처를 한 장에 정리해 두면 좋습니다.

## 코드 연결

`src/escape/SoundManager.java` 가 재생을 담당합니다(JavaFX `javafx.media` 모듈 사용).

- 같은 이름의 `.wav` 를 먼저 찾고, 없으면 `.mp3` 를 찾습니다. 파일이 없거나 재생에 실패하면 소리 없이 그대로 진행합니다.
- wav 는 **16비트**여야 합니다. 24비트 wav 는 16비트로 변환해서 넣었습니다.
- 파일을 바꿀 때는 이름 끝이 `.mp3.mp3` 처럼 두 번 붙지 않게 주의하세요(윈도우 탐색기의 "파일 확장명" 표시를 켜두면 보입니다).
- 게임 설정 메뉴의 **소리 끄기 / 소리 켜기** 로 전체 음소거 (`~/.mystery_story/settings.properties` 에 기억).

연결 위치:
- 사물 클릭, 버튼: `Main` (모든 버튼 공통)
- 방 이동, 방별 배경음, 5분 경고, 아이템, 단서, 정답, 열림, 열쇠 조각, 오답, 힌트, 업적, 결과 화면: `MainController`
- 순서 패널 음: `SequenceController`
- 스톱워치 째깍 소리: `StopwatchController`
- 메인 메뉴 배경음: `Main.showMenu()`
