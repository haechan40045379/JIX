# JIX - Java 방탈출 게임 프로젝트

## 프로젝트 소개

Java Swing 기반의 2D 미스터리 방탈출 게임 프로젝트입니다.

플레이어는 다양한 방탈출 시나리오를 선택하여 게임을 시작하며, 제한 시간 안에 여러 장소를 탐색하고 단서를 수집하여 퍼즐을 해결해야 합니다.

## 개발 환경

- 개발 언어: Java
- GUI 라이브러리: Java Swing
- 개발 도구: Eclipse IDE
- 버전 관리: GitHub

## 주요 기능

- 시나리오 선택 및 게임 시작
- 선택지 기반 스토리 진행
- 장소 이동 및 사물 상호작용
- 아이템 및 단서 수집
- 제한 시간 타이머
- 게임 성공 및 실패 판정

※ 주요 기능은 개발 목표를 포함하며, 단계적으로 구현하고 있습니다.

## 첫 번째 시나리오: 독스프

플레이어는 낯선 공간에 갇힌 상태로 게임을 시작합니다.

방 중앙에 놓인 스프를 안전하게 마셔야 탈출할 수 있지만, 스프에는 독이 들어 있습니다.

플레이어는 여러 방을 조사하고 단서를 수집하여 제한 시간 60분 안에 안전하게 스프를 마시는 방법을 찾아야 합니다.

## 개발 진행 상황

- Java Swing 기반 GUI 프로토타입 구성
- CardLayout 기반 화면 전환 구조 작성
- 시나리오 및 게임 진행 방식 설계
- 주요 게임 시스템 단계별 개발 예정
